# /setup-memory

Configures the Memory pillar: `CLAUDE.md` (project context) và `.claude/memory/` (Tier 3+).

## Mode Detection

```
Có context từ cold-start-interview?
  → Có: dùng answers đã có, skip questions
  → Không (standalone): đọc existing CLAUDE.md nếu có → hỏi missing fields
```

## .claude/memory/ (Tier 3 only)

Tạo structure:
```
.claude/memory/
  MEMORY.md      ← index (loaded every session)
  project.md     ← project facts, key decisions
  team.md        ← team preferences, working style
```

`MEMORY.md` header:
```markdown
# Project Memory Index

*Auto-maintained by /shipwithai-starter. Add entries via direct edit.*

## Active memories
- [project.md](project.md) — project facts
- [team.md](team.md) — team preferences
```

## Write Rules

- Check file exists trước khi write → Overwrite / Merge / Skip?
- Dùng actual values từ interview, không generic text
- Không để [PLACEHOLDER] còn sót sau khi write
