# /setup-ssot

Configures SSOT documentation: `docs/architecture.md`, `docs/adr/`, `docs/CODEMAPS/`.

## Mode Detection

```
Đọc .claude/starter-context.json nếu tồn tại
  → Tồn tại: dùng fields architecture, ssot.adr, ssot.codemaps — skip hỏi
  → Không tồn tại (standalone): hỏi từng selection
```

## Output 1: `docs/architecture.md`

Draft từ Part 2 answers — dùng actual paths, không generic:

```markdown
# Architecture Overview

*Generated by /shipwithai-starter on [DATE]. Edit directly.*

## System overview

[Project name] là [type] được build với [stack].
Architecture style: [monolith / microservices / modular monolith].

## Key layers

| Layer | Directory | Responsibility |
|-------|-----------|----------------|
| [API] | [src/routes/] | [HTTP handlers, validation] |
| [Service] | [src/services/] | [Business logic] |
| [Data] | [src/db/] | [Database access, ORM] |

## Entry points

- `[src/index.ts]` → [main server, port 3000]
- `[src/worker.ts]` → [background job processor]

## External dependencies

| Service | Purpose | Connection |
|---------|---------|------------|
| [PostgreSQL] | [Primary database] | [DATABASE_URL] |
| [Redis] | [Session cache] | [REDIS_URL] |

## Key directories

[paste tree output]

## What to know before touching code

[Gotchas từ interview: generated dirs, build order, sensitive areas]
```

## Output 2: ADR Structure

```
docs/adr/
  README.md              ← index + how to create new ADRs
  ADR-0001-initial-architecture.md
```

`ADR-0001` được draft từ architecture answers. Format từ `adr-template.md`.

## Output 3: `docs/CODEMAPS/`

```
docs/CODEMAPS/
  README.md              ← how to use CODEMAPS
  overview.md            ← high-level codebase map
```

Hướng dẫn: Claude đọc CODEMAPS trước khi touch code trong một area.

## Write Rules

- Dùng actual directory paths từ codebase scan, không generic text
- Check từng output riêng: user có thể chọn create chỉ architecture.md mà skip ADR
- Không overwrite docs đã có không hỏi
