# Team Preferences

*Add working style notes that apply to all Claude sessions.*

## Code style preferences
- Conventional commits: feat/fix/chore/docs: message format
- Gitflow branching: feature/ → develop → main
- No formatters (content-only workspace)

## Review expectations
- Always create PLAN.md and wait for approval before writing new skills or modifying SKILL.md
- Update CHANGELOG.md after every plugin change
- Bump version in plugin.json for every release

## Workflow preferences
- Read all existing SKILL.md files before proposing changes (audit first)
- Edit specific sections rather than rewriting whole files
- One file at a time: modify → verify → next file
